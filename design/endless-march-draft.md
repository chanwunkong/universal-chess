# 無盡行軍（構想草稿）

狀態：試玩版已上線。核心方向見文末「已確認的決定」；數值都是暫定的預設值，玩過再調整。

## 一句話

不再是一關一關重新開始，而是一場**連續的行軍**：棋盤是一條往前延伸的路，你的軍隊一路往前推進，前方不斷出現新的敵人、新的地形和新的國家規則。途中會遇到各種頭目，路的盡頭是最終魔王「王」；打倒王就完成行軍，全軍覆沒就結束。

這是一個**新的模式**，和現有的「無盡征途」並存。

## 和現在「無盡征途」的差別

| | 無盡征途（現有） | 無盡行軍（本草稿） |
|---|---|---|
| 結構 | 9 個獨立關卡，每關重新擺棋 | 一場連續的對局，棋盤一路往前捲動 |
| 敵人 | 每關一支敵軍 | 敵人分批從前方出現 |
| 成長 | 關卡之間的商店 | 行軍途中的營地、補給與招募 |
| 結束 | 打倒國王通關，或戰敗 | 一路打到最終魔王「王」；打倒王即完成，全軍覆沒就結束 |
| 成績 | 走到第幾關 | 前進的距離與擊敗的敵人 |

## 核心玩法

### 1. 捲動的棋盤

```
   ░░░░░░░░    ← 迷霧：只看得到前方幾排，裡面可能藏著敵人
   ♜  ·  ♞     ← 新出現的敵軍
   ·  ·  ·
   ·  ♙  ·  ♙  ← 你的前線
   ♘  旗  ♗    ← 你的旗（要一路護送）
   ════════    ← 後方：捲出畫面的格子
```

- 畫面上永遠是固定高度的一段路，例如 8 排。
- 當你的軍隊推進到前方，棋盤就往前捲動一排：最後面一排移出畫面，最前面生成新的一排。
- **捲動的時機：每過幾個回合自動捲動。** 留在最後一排的棋子會被「拋在後面」而失去，逼你不斷前進。
  - 捲動前要有明顯的倒數提示（例如「再 2 回合捲動」），並標出即將移出畫面的那一排。
- 前方幾排籠罩在迷霧中，靠近才看得清楚。迷霧只影響畫面，不改變規則。

### 2. 路上會遇到的東西

依前進距離逐漸變難、變豐富：

| 遭遇 | 說明 |
|---|---|
| 巡邏小隊 | 少量敵兵，從前方迎面而來 |
| 敵方據點 | 一塊有國家主題的敵陣，有自己的旗，奪下後得到大量戰功 |
| 待救援的棋子 | 被困在路上的中立棋子，走到旁邊就加入你的軍隊（招募來自各國的棋子） |
| 補給 | 走到上面就得到戰功點數 |
| 地形 | 不規則的路面：狹窄的關口、斷橋（空洞）、分岔路 |
| 頭目 | 每走一段距離出現一支強大的敵軍，例如完整的將棋軍、象棋軍；打倒後得到豐厚獎勵 |
| 最終魔王「王」 | 路的盡頭。像打魔王的劇情一樣，一路打過各種頭目，最後要將死王才算完成行軍 |

### 3. 國境與規則

這是最能發揮「萬象棋盤」特色的部分：**路會穿越不同的國家，每個國家有自己的規則。**

- **進入一個國家，全場就換成那一國的規則。** 例如進入「日本國境」後，雙方吃掉的棋子都可以打入；進入「泰國國境」後，兵在第六排升變。
- 國境在棋盤上用顏色或界碑標示，切換規則時畫面會明確提示「已進入日本國境：打入生效」，並可以點開那張規則卡。
- 玩家一路走過去，就自然把各國規則都體驗一遍。
- **切換時機：** 棋盤捲動、己方陣地那一排（畫面第 2 排）越過國境線時，全場切換。規則只在捲動時改變，不會因為棋子前後移動而來回切換。換規則時，手上的持駒保留，但只有在允許打入的國家才能打入。
- 這延續了規則圖鑑「讓使用者熟悉規則」的目的，但改成邊走邊學。

### 4. 營地與成長

- 路上每隔一段距離有一個**營地**。抵達營地時，可以用戰功招募棋子、升級棋子。
- 俄羅斯方塊擴充的概念可以改成**架橋**：用方塊填補路上的空洞或斷橋，開出新的路線。
- 難度沿用現在的設計：
  - 簡單：在營地可以讓陣亡的棋子歸隊。
  - 困難：陣亡就永久消失。

### 5. 結束與成績

- 棋盤上沒有任何己方棋子、手上也沒有援軍（全軍覆沒），行軍就結束。
- 打倒最終魔王「王」就完成行軍。
- 成績 = 前進距離，另外記錄擊敗的頭目、敵人數與穿越過的國家；完成行軍另有紀錄。
- 每次的路都是隨機生成的，所以每一場都不一樣。

## 需要的引擎擴充（初步評估）

| 功能 | 難度 | 說明 |
|---|---|---|
| 棋盤捲動 | 中 | 在兩步之間把局面整體平移一排，並生成新的一排；引擎本身不必改，由行軍模式管理 |
| 迷霧 | 低 | 只影響畫面；電腦對手仍看得到全部（或之後再限制） |
| 依國家切換規則 | 中 | 全場共用同一套規則，所以引擎不必改；行軍模式在越過國境時換掉整套規則即可。要處理的是切換時的過渡，例如持駒、升變區、已經升變的棋子 |
| 不規則路面 | 已完成 | 沿用無盡征途做好的空洞機制 |
| 電腦對手 | 中 | 棋盤保持固定的小視窗，電腦的計算量就不會隨著距離變大 |

## 已確認的決定

1. **棋盤捲動：** 每過幾個回合自動捲動（方案 B），被留在最後一排的棋子會失去。
2. **國境規則：** 進入一個國家，全場就換成那一國的規則。
3. **王：** 王是路盡頭的最終魔王。途中會遇到各種頭目，最後將死王才算完成行軍。
4. **模式定位：** 無盡行軍是新的模式，現有的「無盡征途」保留。

## 仍待決定的細節

- 每隔幾回合捲動一次？是否隨距離加快？
- 走到王之前大約要經過幾個國家、幾個頭目（決定一場行軍的長度）。
- 營地的間隔與商品內容。

## 試玩版的預設值

- 視窗 8 寬 × 9 高，最上面 2 排是迷霧；開局前 5 排沒有敵人。
- 捲動：簡單每 4 步、困難每 3 步捲動一排；每前進 60 排再快一步（最快每 2 步）。最後一排在即將捲動時以紅色標示。
- 每個國家 24 排，依序經過 5 個國家；每個國家第 20、21 排是頭目（奪下頭目軍旗得 10 點）。最後是王城：西洋棋的兵與王一族，規則換成將死。
- 沒有軍旗：試玩時發現每隔幾步就得移動軍旗太累，因此取消，改為全軍覆沒才結束。開局 5 枚棋子。
- 國家規則：日本＝吃掉的棋子進入手中、可打入任何空格；韓國＝可以停著；其他國家目前沒有在奪旗模式下會生效的規則，主要差別是敵軍的棋種。
- 路上物品：★ 補給（3 點）、✚ 援軍（隨機一枚棋子進入手中）。
- 營地每 16 排一次：招募援軍、買架橋方塊（蓋在空洞上變成路）；簡單模式可讓陣亡棋子歸隊。
- 援軍以打入的方式部署到己方最後兩排（日本國境內可打在任何空格），部署算一步棋。
